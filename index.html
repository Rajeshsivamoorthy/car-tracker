Save to GitHub

Every change is saved to a data file in a GitHub repository, so any device you connect shows the same numbers. Use a separate private repository for the data.

Advanced: file name and branch
One token, limited to the data repository, with Contents set to read and write. Create it on GitHub: the name and permission are filled in. On that page choose "Only select repositories" and pick your data repository. The token stays in this browser only.
